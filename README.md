# manrus
Manrus é um app financeiro focado em inteligencia artificial para facilitar a vida do usuário. Com ele você poderá gerenciar suas finanças de forma simples e intuitiva.

## Funcionalidades

- Controle de gastos
- Controle de receitas
- Controle de investimentos
- Controle de cartões de crédito
- Controle de metas
- Dashboard interativo e intuitivo
- Análises personalizadas
- Dicas financeiras
- Notificações personalizadas
- Analises feitas por IA

## Tecnologia

- React Native
- Expo
- Firebase
- TypeScript
- Tailwind CSS
- PHP
- Laravel
- PostgreSQL
